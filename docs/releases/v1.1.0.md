# ProxyNetworker v1.1.0

本版重点改进 Linux 虚拟局域网吞吐、默认选路稳定性与故障回退，同时完善加密兼容性、节点拓扑和管理体验。

## 主要更新

- Linux 数据面支持 `recvmmsg/sendmmsg` 批量收发、TUN `vnet_hdr/GSO`，以及外层 UDP `UDP_SEGMENT/UDP_GRO`。不支持相关内核或路径能力时保留普通收发回退，每个原始帧仍独立认证。
- 优化发送队列缓冲区所有权、Mesh 收发与原地加解密，减少重复复制、分配和路由维护开销。
- 默认启用稳定直连选路：对经过有效双向探测的私网候选给予有限偏好，减少小幅评分波动导致的频繁切路；不依赖固定 IP 或候选白名单。私网明显更差或失效时仍可使用其他直连候选或中继。
- 修正探测统计和存活判断：在途探测不计为丢失，未知、重复或过期 ACK 不刷新有效证明；持续发送或入站流量不再掩盖单向故障。
- 默认使用 AES-GCM，增加系统与托管后端互操作检查和 `crypto self-test`。可配置 HMAC-only 模式，但该模式不提供内容机密性。
- 完善持久化虚拟 IPv4、实时拓扑与流量统计、Token 单实例锁、配置刷新重连，以及中英文管理界面。
- 提供可选 Linux 私网网卡 offload 管理工具，记录原值并支持停止恢复、身份校验和能力不足时的软件降级。

## 性能与验证

本轮两个原生 Linux x64 测试节点使用 AES-GCM、MTU 1400、应用 GSO/GRO，以及经过验证的私网网卡 UDP segmentation。采用 256 MiB HTTP/sendfile 文件传输，速率单位为十进制 MB/s：

| 项目 | 文件数 | 平均吞吐 |
| --- | ---: | ---: |
| 普通私网 TCP 基线 | 6 | 62.64 MB/s |
| 原配置自动选路，稳态正向 | 9 | **58.75 MB/s** |
| 原配置自动选路，稳态反向 | 9 | **56.59 MB/s** |

正向达到本轮内网基线的约 **93.8%**，九次均在 58.72–58.77 MB/s。不是仅挑选私网成功样本，也不是所有硬件和网络环境的固定速度承诺。

- 原生 Linux x64 核心回归：158/158 通过，无跳过。
- Windows 核心回归：143 项通过，6 个 Linux 专用测试方法跳过。
- 已实际验证单向私网故障后的公网回退、恢复后的私网回切，以及旧程序恢复后再次启用新版。
- 双向普通 ICMP 各 30/30、1400 字节 DF 满 MTU 包各 10/10；保留原配置、Token 和虚拟地址。
- 本轮传输窗口没有新增 UDP 收发缓冲区错误或观察到的接口、qdisc 丢包。

## 升级与回退

- 升级前备份现有程序和配置，保留原 `appsettings.json`，不要用安装包中的示例配置覆盖现网 Token。客户端仍可从原工作目录无参数启动。
- `virtualNetwork.stableDirectPathSelection` 省略时默认为 `true`；显式设置为 `false` 并重启，可关闭私网偏好和切路滞回，但不会撤销探测与存活判断的安全修正。
- 应用自动尝试 UDP offload；网卡级设置是独立、显式选择的运维操作，不会在任意主机上自动修改网卡。先核对实际私网出接口、驱动与能力，再参考 `scripts/Manage-LinuxUdpOffload.py`。
- 应用数据面回退、旧程序恢复与网卡原值恢复是独立层次；不要为恢复性能关闭 AES-GCM。
- 建议服务端和客户端一并升级，以使用新增配置、拓扑与管理能力。

## 已知边界

- 冷启动仍有发现与切路阶段。本轮首个完整文件为 40.36 MB/s，随后两个为约 58.77 MB/s。
- 既有探测有效期为 20 秒，故障切换不是无缝或瞬时的。本轮单向故障约 17 秒切到公网，解除后约 37 秒回到私网；时间取决于故障前探测时刻和恢复情况。
- 反向仍有少量 TCP 重传，重载并发稳定性不等同于单连接吞吐结果。
- 上述吞吐和真实 TUN 验证限于本轮 Linux x64 环境；Windows、Linux ARM64 的发布构建及加密自检不代表已完成同等真实数据面压测。未执行整机重启验证。
