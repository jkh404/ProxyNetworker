# ProxyNetworker v1.2.0

本版新增独立的 Avalonia 可视化客户端和 Android 开发预览，保留原有 CLI；同时加入 macOS CLI 后端及原生 CI 开发预览。

## 主要更新

- 新增 `Client.Runtime` 共享配置、管理 API、端口隧道与网络状态；CLI 仍可独立、无参数读取原 `appsettings.json` 启动，保持原 Token 和虚拟地址。
- Windows GUI 使用 Avalonia 12、TKCode.Arc / Arc.Mobile 和 Lucide。支持导入/编辑配置、连接状态、真实流量及节点、日志、脱敏诊断、托盘后台、单实例唤回与退出清理。
- GUI 以普通权限运行，仅虚拟网络的独立 Worker 请求管理员权限；端口隧道不要求提权。本地控制通道使用有限命令、短期认证和有界消息，不传输数据面报文。
- Android 使用原生 VPN 授权、受保护的传输 Socket、内核 TUN 与前台通知。会话服务与系统 VPN 设备在同一进程中分离，支持常规后台和系统投递的恢复；主动断开、通知停止及撤销授权会清理连接。
- 增加 Android 通知与电池策略状态和系统设置入口，修复页面滚动、安全区、中文字体及通知重复更新。Spyglass 只在 Debug 启用，不进入 Release。
- macOS CLI 新增 IPv4 utun、Darwin 原生桥接、报文边界和所属资源清理；Apple Silicon / Intel 分别原生 AOT 构建及隔离冒烟。仍为 CI 开发预览，不宣称 Mac 真机验收。
- 改进拓扑直连观测与流量显示，及时发布新确认路径的 link-state，补充回归；普通权限进程可继续使用管理员遗留锁文件，不绕过 Token 单实例互斥。

## 验证范围

- 本地 .NET 回归：234 通过，6 个 Linux 专用测试跳过；Release 解决方案构建 0 警告、0 错误。
- Windows x64：真实 Wintun、普通及满 MTU ICMP、TCP/UDP 有效载荷、后台、单实例、托盘退出与 Worker 清理均有实测。
- Android 16 / API 36 x64 模拟器：真实授权与 TUN、UDP/AES-GCM、MTU 1400、TCP/UDP、后台任务移除、锁屏 Doze、授权撤销、通知停止与 Force Stop 均有实测。
- 最终 Android 包三轮无 Activity 的受控进程回收后自动重建进程及 TUN，耗时 3.33 / 6.12 / 18.16 秒；每轮满 MTU ICMP 10/10、TCP/UDP 完整性通过。不是任意系统的固定恢复时限或永不被杀保证。
- 双架构 Android 构建检查单一 ABI、非 Debug、版本、内嵌程序集及禁止内容。ARM64 只完成构建，未做手机真机数据面测试。
- 详细结果和早期失败记录见 `docs/2026-11-03-client-acceptance-report.md`。远程构建、原生 CLI 加密自检及发布资产以本标签的 Actions 记录为准。

## 已知边界

- GUI/Android 在稳定版本标签中仍标记为开发预览；Linux/macOS GUI、Android ARM64 手机、厂商省电策略和 Wi-Fi/蜂窝切换未完成验收。
- 不绕过系统 Force Stop，不默认开机启动、开启始终在线 VPN、改变电池豁免或持有无限期唤醒锁。
- macOS 真机测试按既定安排暂缓；Mac CLI 预览包仍从独立 macOS Actions artifact 获取，仅 ad-hoc 签名，未公证，不列为本 Release 正式平台资产。
- 冷启动一次 3 包探测曾为 2/3，失败样本保留；UI“运行中”表示本地接口与会话状态，不保证每个远端节点可达。
- 本次不重做上一版 Linux 吞吐压测，不将其约 93.8% 的结果外推到新增 GUI 或移动平台。

源码与资产只包含公开示例，不包含现网 Token、密钥、数据库、签名私钥、配置备份或原始运维证据。
